# Etkinlik ekibi medya teslimi

20 Ekim 2026: Etkinlik Departmanı Başkanı **Halis Can Sağır** açılış videosu ve detay fotoğrafı kullanır. Diğer kişiler yalnız detay fotoğrafı kullanır.

| Dosya | Ölçü | Kullanım |
|---|---|---|
| `Ed-Baskan/ed-baskan-halis-acilis.mp4` | 1920×1080 | Halis açılışı; yerleştirildi |
| `Ed-Baskan/ed-baskan-halis-detay.webp` | 1600×1100 | Halis detay / video kapağı; yerleştirildi |
| `etkinlik-ekip-efe-tutucu.webp` | 1600×1100 | Efe Tutucu detay |
| `etkinlik-ekip-aybey-detay.webp` | 1600×1100 | Aybey detay |
| `etkinlik-ekip-fatih-soyer.webp` | 1600×1100 | Fatih Soyer detay |
| `etkinlik-ekip-eren-bozacı.webp` | 1600×1100 | Eren Bozacı detay |

Sıra: Halis → Efe → Aybey → Fatih → Eren. Kişisel başkan bilgisi `Ed-Baskan/ed-baskan.md` dosyasındadır. Ekibe ortak açılış videosu gerekmez.
