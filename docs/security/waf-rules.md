# CDN/WAF ve origin kurulumu

Durum: yerel proxy politikası uygulanmış/test edilmiş; CDN tenant, gerçek DNS/VDS IP ve ağ kısıtı henüz kurulmadı. Kullanıcı domain/VDS'yi daha sonra bağlayacak. Yerel testler gerçek WAF yanlış-pozitif oranı ölçümü değildir.

1. Node uygulamasını 127.0.0.1'e bağla; PostgreSQL/depo yönetim portlarını internetten açma. Docker yayını varsa host 127.0.0.1 port mapping kullan. Nginx yalnız TLS reverse proxy olsun; CDN IP listesini resmi sağlayıcıdan güncel alıp firewall'da 443 allowlist uygula. SSH yönetim IP'sini kilitlemeden doğrula. Health/worker dahili kalsın.
2. CDN cache: /admin, /api, /kart, /takim, /basvuru, /makbuz, /yayin-onayi bypass. Nonce taşıyan HTML zaten no-store. Yalnız /_next/static ve doğrulanmış public medya cachelenir. Challenge sayfasını AJAX JSON yanıtı gibi sunma; form endpointinde Turnstile kullan.
3. İlk eşikler (yük kabulüyle ayarlanacak): /api/admin/login POST IP başına 10/dakika managed challenge; form/ulujam apply POST 30/dakika; team login 10/dakika; private card/receipt read 60/dakika; admin media POST 10/dakika ve 8MiB+64KiB gövde. Genel sayfalarda 120/dakika; RSC/prefetch ve statik dosyaları bot testinden hariç tut. IP kimliği yalnız güvenilir edge'den alınır. Bu eşikler CDN'ye burada yazılmış değildir.
4. Managed SQLi/XSS kuralları önce log modunda; form metninde Türkçe karakter, URL, apostrof, kod örneği ve oyun açıklamasını yanlış pozitife karşı dene. Kuralı bütün site için kapatma; dar rota/alan istisnasını kanıtla. Next RSC/ServerAction headerlarını silme.
5. ORIGIN_SHARED_SECRET opsiyonel ikinci kontroldür. Edge x-uludott-origin headerını her zaman kendi sabit sırrıyla override eder; kullanıcı headerını iletmez. Key repo dışında; uygulama eşitliği constant-time kontrol eder, uygulamaya iletmeden headerı siler. Statik yollar dahil gate çalışır. Secret aktifken CDN olmadan yerel siteye erişim reddedilir; key sızıntısında rotate et. Salt header firewall yerine geçmez.

Yerel edgeDecision testleri normal JSON/Türkçe metin, apostrof arama, RSC header ve 8MB multipart upload'ı kabul eder; iri gövdeyi, yanlış/yok origin keyini reddeder. Gerçek yük, edge rate dağılımı, kullanıcı IP paylaşımı, origin direct-IP engeli ve yanlış pozitif ölçümü VDS yayın kabulünde ayrı raporlanacak.

[Cloudflare Turnstile sunucu doğrulaması](https://developers.cloudflare.com/turnstile/get-started/server-side-validation/) tokenı yalnız sunucuda doğrular. required mod için sitekey+secret ve APP_URL hostname/action aynı widget ile doğrulanmalı; bir tokenı her submit denemesinden sonra yenile. Bu projede form_submit ve ulujam_apply aksiyonları vardır. Eksik key/token/yanlış hostname/action/replay reddedilir. Dummy key sadece izole test ortamında kullanılır; canlı tenant kurulumu ayrı kabul gerektirir.
